# 😊 Sentiment Analyzer

A simple **Sentiment Analysis** project using **Python and NLTK** to analyze text and determine whether the sentiment expressed is **Positive, Negative, or Neutral**.

## 📌 Project Description

Sentiment Analysis is an important Natural Language Processing (NLP) technique used to identify the emotional tone of a piece of text.

This project uses **NLTK (Natural Language Toolkit)** to process and analyze text and classify its sentiment.

## 🛠️ Technologies Used

* 🐍 Python
* 🧠 NLTK
* 📝 Natural Language Processing (NLP)

## ✨ Features

* 😊 Detects positive sentiment
* 😐 Detects neutral sentiment
* 😞 Detects negative sentiment
* 🔤 Processes text using NLP techniques
* ⚡ Simple and easy-to-use Python implementation

## 🚀 How to Run

1. Make sure Python is installed on your system.
2. Install NLTK:

```bash
pip install nltk
```

3. Run the Python file:

```bash
python sentiment_analysis.py
```

4. Enter the text you want to analyze and view the sentiment result.
